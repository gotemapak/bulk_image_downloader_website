Frequently Asked Questions

Straight answers about how Bulk Image Downloader works, where it works, what happens to your data, and how to filter down to exactly the images you need.

Install the Extension Read the Step-by-Step Guide

How do I download all images from a website in Chrome?

Install the Bulk Image Downloader extension, then open the webpage containing the images. Click the extension icon or its floating widget to scan the page — it automatically detects all images, including thumbnails and high-resolution versions. Select the images you want, optionally filter by size or format, and download them all at once. See the full step-by-step guide for details.

Does it work on any website?

Yes. Bulk Image Downloader scans the page you're currently viewing, whatever site it's on — it isn't limited to a specific list of supported sites. It works the same way on product pages, galleries, portfolios, blogs, and any other webpage that displays images.

Does it collect my data?

No. Bulk Image Downloader does not collect your data. Image detection and downloading happen locally in your browser, with nothing sent to an external server. See how detection works for more detail.

Does it work offline?

Yes. Because scanning and downloading run locally in your browser rather than through a remote service, Bulk Image Downloader works offline — no account, sign-up, or internet-based processing is required.

What image formats and sizes can I filter by?

You can filter the images Bulk Image Downloader detects on a page by size, format, or source, and sort them by dimensions or file size before downloading. This covers the common web image formats a page may contain, such as JPG, PNG, WebP, GIF, and SVG.

Can it find full-resolution images, not just thumbnails?

Yes. Many pages only display small preview or thumbnail images while linking to larger originals behind the scenes. Bulk Image Downloader's Smart Detection finds those hidden full-resolution originals too, so you aren't stuck downloading low-res previews.

How do I pin the extension?

Click the puzzle-piece icon in Chrome's toolbar, find Bulk Image Downloader in the list, and click the pin icon next to it to keep it visible in your toolbar.

Still have questions?

Install Bulk Image Downloader from the Chrome Web Store and try it on your own pages.
